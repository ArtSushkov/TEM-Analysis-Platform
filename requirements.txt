#
# --- Part 1 · Python wrapper (installed by pip, this line) ------------------
pytesseract>=0.3.10
#
# --- Part 2 · The Tesseract-OCR ENGINE (a separate program, NOT a pip
#              package — pip alone can never fix the error above) -----------
#
# WINDOWS, step by step:
#   1. Install the engine (pick ONE of these ways):
#        winget install -e --id UB-Mannheim.TesseractOCR
#      or download the 64-bit installer from
#        https://github.com/UB-Mannheim/tesseract/wiki
#        (file name: tesseract-ocr-w64-setup-5.3.x.x....exe)
#      or, if you use Chocolatey:
#        choco install tesseract
#   2. Keep the DEFAULT install folder:
#        C:\Program Files\Tesseract-OCR
#      The application AUTO-DETECTS tesseract.exe there (and in
#      C:\Program Files (x86)\Tesseract-OCR) even when the folder is NOT
#      on your PATH — after installing, just restart the Streamlit app.
#   3. (Optional) To make the engine visible to ALL programs, add the
#      folder to PATH:
#        Settings -> System -> About -> Advanced system settings ->
#        Environment Variables -> Path -> New ->
#        C:\Program Files\Tesseract-OCR -> OK,
#      then close and reopen the terminal and start Streamlit again.
#   4. Sanity check (cmd):
#        "C:\Program Files\Tesseract-OCR\tesseract.exe" --version
#      (must print e.g. "tesseract v5.3.x")
#
# LINUX:   sudo apt install tesseract-ocr
# macOS:   brew install tesseract
#
# After (re)installing the engine, RESTART the Streamlit app — the OCR
# availability check runs once at startup. If the button is still disabled,
# the app will show the exact reason next to it (wrapper missing vs engine
# missing vs engine found but broken).
