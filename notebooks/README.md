# Notebooks — ML Research for TEM Layer & Grain Segmentation

This directory contains Jupyter notebooks for researching and training ML models
for two tasks:

## Notebooks

### `01_layer_detection_microsam.ipynb`

Fine-tunes Micro-SAM (ViT-B LM) on TEM cross-section images for **layer detection**.

**Task:** User clicks on a pixel inside the layer → model predicts the layer mask.

**Model:** Micro-SAM ViT-B LM (fine-tuned on light microscopy, ~350 MB).

**Training data:** `training_data/layer_detection/`
- `images/` — full TEM cross-section images (TIFF, grayscale)
- `masks/` — binary masks of the layer (0 = not layer, 1 = layer)
- `points.json` — click point [col, row] inside the layer for each image

**Environment:** Google Colab (GPU). Install micro-sam:
```python
!pip install micro-sam
```

### `02_grain_segmentation_unet.ipynb`

Trains U-Net (ResNet-18 encoder) on cropped layer images for **grain boundary detection**.

**Task:** Given a cropped layer image → model predicts grain boundaries → watershed → individual grains.

**Model:** U-Net with ResNet-18 encoder (`segmentation_models_pytorch`).

**Training data:** `training_data/grain_segmentation/`
- `images/` — cropped layer images (TIFF, grayscale, layer bbox crop, any size)
- `boundaries/` — binary boundary targets (0 = no boundary, 255 = boundary)
- `labels/` — labeled images (0 = bg, 1 = grain 1, 2 = grain 2, ...) for evaluation
- `layer_masks/` — 255 = inside the layer, 0 = outside. Out-of-layer pixels get
  `ignore_index=255` in the loss, so neighboring layers caught by the tilted-layer
  bbox do not pollute training (replaces the old mean-fill approach).

**Training details:**
- Random 512×512 tiles are cut from the variable-size crops (`PadIfNeeded` +
  `RandomCrop`), native resolution is preserved (no resize — grain/lattice scale
  stays consistent).
- Validation/inference runs on the full image padded to a multiple of 32.
- Rotational diversity comes from flips + `RandomRotate90` (lossless); images are
  not derotated.

**Environment:** Google Colab (GPU). Install:
```python
!pip install segmentation-models-pytorch
```

## Data preparation

Run `export_training_data.py` (in the project root) to extract training data
from JSON reports generated by the Streamlit app:

```bash
python apps/02_grain_analyzer/export_training_data.py \
    --reports-dir path/to/json_reports/ \
    --images-dir path/to/tiff_images/ \
    --output-dir training_data/
```

This creates the `training_data/layer_detection/` and `training_data/grain_segmentation/`
directories with properly formatted images, masks, boundaries, and labels.

## Workflow

1. **Annotate** — use the Streamlit app's Manual tracing mode to trace grains on
   10-50 TEM images. Save JSON reports for each.
2. **Export** — run `export_training_data.py` to convert JSON reports to training data.
3. **Train** — open the notebooks in Google Colab, upload the training data, run.
4. **Integrate** — download the trained model checkpoint, place it in
   `~/.cache/tem_grain_analyzer/`, select the new method in the Streamlit app.
